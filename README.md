# 対戦オセロ (Reversi Online)

ブラウザで誰でも完全無料・登録不要ですぐに遊べる本格対戦オセロ（リバーシ）Webアプリケーションです。

## 主な特徴
- **WebRTC (PeerJS) オンラインP2P対戦**: サーバー代0円・登録不要。部屋を作成して発行された招待URLをLINEやメール等で送るだけで、ブラウザ同士が直結して低遅延でリアルタイム対戦できます。
- **本格CPU対戦**: 初級・中級・上級の3段階の思考AI（開放度理論・角重視・Minimax / Alpha-Beta探索）を搭載。
- **ローカル2人対戦**: 1台のPC・タブレット・スマートフォンを挟んで対面で交互に着手して対戦可能。
- **リアルな3Dアニメーションと打石音**: Web Audio APIにより外部音源不要で生成される心地よい「パチッ」という着手音と、石がクルッとひっくり返る3Dフリップアニメーション、勝利時の紙吹雪演出。
- **アシスト機能**: 打てるマスのガイド表示、裏返る石の枚数プレビュー、自動パス判定、待った（アンドゥ）、石数比率バー。

## ローカル開発とビルド
```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# 本番用ビルド
npm run build
```
